## 怎么确认这个文件是好的

三步，都能自己跑：

```bash
# 1. 大小和 md5 对上
ls -l global-metadata.fixed.dat
md5sum global-metadata.fixed.dat

# 2. magic 和版本号对上（前 8 字节）
xxd -l 8 global-metadata.fixed.dat
# 期望：af1b b1fa 1b00 0000
#       即 magic=0xFAB11BAF（小端），version=27

# 3. 最后一段不越界
python3 -c "
o,s=0x01EC0470,4084
print('段尾:', hex(o+s), '文件长:', hex(32248932), '一致:', o+s==32248932)
"
```

三条都过，说明文件结构完整、可以直接喂工具。
